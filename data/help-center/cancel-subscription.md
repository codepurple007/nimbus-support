# Cancel a Nimbus subscription

You can cancel any time. Cancellation stops the **next** renewal. It does not automatically refund the current period.

1. Go to **Settings → Billing → Cancel plan**.
2. Confirm. You keep access until the period end date shown on that screen.
3. To also request a refund, read the refund policy. Refunds are only for purchases within 14 days.

The support agent can explain these steps. It cannot cancel the account itself. If the billing page fails, open a ticket for a human.
